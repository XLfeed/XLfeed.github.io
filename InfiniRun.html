MY FIRST UNREAL ENGINE PROJECT

InfiniRun

An endless runner developed as a one-month exploration of Unreal Engine.

Solo Project • Unreal Engine • 1 Month

About the Game

InfiniRun is an endless runner developed as a solo project using Unreal Engine.

The project was created as an opportunity to explore a different game engine and broaden my development experience beyond Unity.

Players control their character using horizontal movement inputs as they progress through the endless runner.

My Role

InfiniRun was developed independently over the course of one month.

As my first Unreal Engine project, the focus was on learning a new development environment while creating a playable endless runner.

Unreal Engine Exploration

Used InfiniRun as an opportunity to transition beyond my usual Unity development workflow.

Gained experience developing a game in Unreal Engine through a complete solo project.

Gameplay Development

Developed an endless runner experience featuring horizontal character movement.

Integrated gameplay controls with a pause function and mouse-operated menus.

Independent Development

Took responsibility for developing the project independently within a one-month timeframe.

The project served as a practical introduction to working with a different game engine.

InfiniRun uses keyboard controls for gameplay and mouse input for menu navigation.

A / D Control the character
ESC Pause the game
Mouse Navigate menus
